# Guide de contribution 🤝

Merci de prendre le temps de contribuer à ce projet de sensibilisation à la vie privée et de résistance à la surveillance de masse ! Toutes les contributions sont les bienvenues, qu'il s'agisse de corriger des fautes d'orthographe, de mettre à jour le statut légal de Chat Control ou de proposer de nouvelles astuces techniques.

## Comment contribuer ? 🚀

### 1. Signaler un problème ou une mise à jour (Issues)
Si vous constatez une erreur, une information obsolète ou si vous avez une idée d'amélioration :
* Vérifiez d'abord dans les **Issues** existantes si le sujet n'est pas déjà en cours de discussion.
* Ouvrez une nouvelle *Issue* en décrivant clairement le problème ou la mise à jour nécessaire.

### 2. Proposer des modifications (Pull Requests)
1. **Forkez** le dépôt.
2. Créez une branche descriptive : `git checkout -b feature/nouvelle-astuce`
3. Effectuez vos modifications.
4. Commitez vos changements : `git commit -m "Ajout d'une astuce de configuration"`
5. Pushez votre branche : `git push origin feature/nouvelle-astuce`
6. Ouvrez une **Pull Request**.
